1. Introduction

Types of machine learning explains different types of algorithms that use in Machine learning and Artificial intelligence based on their outcome.These algorithm can be used and learn in different ways with the data and generalize to unseen data. Therefore, it does not need any additional instructions to deal with the data.

Supervised Learning

In this learning method, the computer system is trained using a dataset in which each input is associated with its corresponding label. Because the data are already labeled, it is easier for the computer to learn the relationship between the input data and the desired output.

Mathematically, each training sample is represented as:

(Xi, Yi) ∼ P(X, Y)

where:

  • Xi = Input feature vector
  • Yi = Corresponding target label
  • P(X, Y) = Joint probability distribution of the input features and labels

Semi-supervised Learning

In this learning method, the computer system is trained using little labeled data and unlabeled data to understand patterns without human intervention or a target output. Therefore, the algorithm starts to learning with the small labeled data and applie the pattern to unlabeled ata it fee for the system.

Unsupervised Learning

In this learning method, the computer system is trained using unlabeled data to understand patterns without human intervention or a target output.

Self-Supervise Learning

This is artificial intelligence learning method where model learn by itself. It can create its own label data using raw and unlabeled data.

Reinforcement Learning

The reinforcement learning is similar as self-learning method which use an agent to learn about environment. This learning methods behave by getting positive rewards for target acheivement and lose points when program could not acheive the target.
