1. Introduction

Types of machine learning describe different approaches used to train machine learning algorithms.

2. Supervised Learning

In this learning method, the computer system is trained using a dataset in which each input is associated with its corresponding label.

Because the data are already labeled, the computer can learn the relationship between the input data and the desired output.

Mathematically, each training sample is represented as:

(Xi, Yi) ∼ P(X, Y)

3. Unsupervised Learning

In this learning method, the computer system is trained using unlabeled data to understand patterns without human-provided target outputs.

Xi ∼ P(X)

4. Self-Supervised Learning

In self-supervised learning, the model learns from unlabeled data by generating training targets from the data itself.

5. Semi-Supervised Learning

Semi-supervised learning uses a combination of labeled and unlabeled data to train a model.

6. Reinforcement Learning

In reinforcement learning, an agent learns by interacting with an environment and receiving rewards or penalties.
