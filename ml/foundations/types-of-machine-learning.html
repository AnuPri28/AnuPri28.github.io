1. Introduction

Types of machine learning describe different approaches that are used to train machine learning algorithms. These algorithms learn from data in different ways and can generalize their knowledge to unseen data.

Therefore, machine learning systems can learn patterns from data without requiring explicit instructions for every situation.

The main types of machine learning are:

  • Supervised Learning
  • Unsupervised Learning
  • Self-Supervised Learning
  • Semi-Supervised Learning
  • Reinforcement Learning

2. Supervised Learning

In this learning method, the computer system is trained using a dataset in which each input is associated with its corresponding label.

Because the data are already labeled, the computer can learn the relationship between the input data and the desired output.

Mathematically, each training sample is represented as:

(Xi, Yi) ∼ P(X, Y)

where:

  • Xi = Input feature vector
  • Yi = Corresponding target label
  • P(X, Y) = Joint probability distribution of the input features and labels

Input → Model → Output

Labeled data → Machine Learning Model → Predicted Output

💡 My initial understanding:

The model learns from examples where both the input and the correct answer are already provided.

3. Unsupervised Learning

In this learning method, the computer system is trained using unlabeled data to understand patterns and relationships without human-provided target outputs.

Mathematically, an individual input sample can be represented as:

Xi ∼ P(X)

4. Self-Supervised Learning

In self-supervised learning, the model learns from unlabeled data by generating training targets from the data itself.

5. Semi-Supervised Learning

Semi-supervised learning uses a combination of labeled and unlabeled data to train a machine learning model.

6. Reinforcement Learning

In reinforcement learning, an agent learns by interacting with an environment and receiving rewards or penalties based on its actions.
