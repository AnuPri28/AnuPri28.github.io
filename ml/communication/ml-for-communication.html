1. Introduction

A communication system mainly consists of a transmitter, a communication channel, and a receiver. These components work together to transmit information from one point to another.

In a traditional communication system, the transmitter processes and encodes the information before sending it through the communication channel. The receiver then receives the transmitted signal and decodes it to recover the original information.

Modulation is also an important part of the transmission process. It converts the information signal into a form that can be efficiently transmitted through the communication channel.

Traditional Communication System

Information → Encoder → Modulator → Channel → Demodulator → Decoder → Recovered Information

Machine Learning introduces a different approach to communication systems. Instead of designing every processing stage independently, a neural network can learn how to represent, transmit, and recover information directly from data.

In an end-to-end learned communication system, a neural network can learn the functions of the transmitter and receiver jointly. This can potentially simplify the communication pipeline and allow the system to adapt to complex channel conditions.

Machine Learning-Based Communication

Information → Neural Network Transmitter → Communication Channel → Neural Network Receiver → Recovered Information
